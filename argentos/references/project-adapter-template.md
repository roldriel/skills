# ARgentOS Project Adapter

This project is governed by ARgentOS.

The canonical ARgentOS root is:

`ARGENTOS_ROOT=.argentos`

Before performing project work, read:

`.argentos/.agents/INDEX.md`

The file `.argentos/AGENTS.md` is the installed ARgentOS protocol entry point.

This file is only a project-facing adapter. It does not replace the protocol's normative authority.

If ARgentOS state or project-specific operational context is required, consult `.argentos/.project/` according to the ARgentOS command contract.
